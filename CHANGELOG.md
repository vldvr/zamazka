# Изменения

## 1.0.0

Первая версия.

- Проверка новых скриншотов из четырёх источников: системные снимки в файл и в буфер, CleanShot X в файл и в буфер (включая историю CleanShot). Снимок узнаётся по атрибуту `kMDItemIsScreenCapture` на файле, по имени на любом языке macOS и по счётчику изменений буфера.
- Поиск на устройстве через Vision: телефоны, карты (Луна), счета, паспорт РФ, СНИЛС и ИНН с контрольными суммами, полис ОМС, адреса, госномера, заказы и трек-номера (S10), имена и даты рождения рядом с подписями, почта, IP, ключи API и пароли, QR-коды и штрихкоды, лица, свои слова.
- Карточка под значком в строке меню: включить и выключить находку, дорисовать область, «Скрыть», «Вернуть», перетащить результат в чат.
- Сплошная заливка по умолчанию, цвет фона снаружи области или шум без исходных пикселей. Размытия нет намеренно.
- Оригинал для «Вернуть» только в памяти, время хранения настраивается, по истечении затирается.
- Предупреждения о миниатюре macOS и о папке снимков в облаке.
